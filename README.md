## About This Repository
This repository documents my journey through the DecodeLabs Data Analytics Internship Program. The projects cover different stages of the data analysis process, from data cleaning and exploratory analysis to SQL-based business analysis and data visualization.
The main goal throughout the internship was to turn raw data into meaningful insights that can support better business decisions.
